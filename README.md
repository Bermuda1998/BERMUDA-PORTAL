## ⚡ Project Philosophy & Goal

**Bermuda Portal** is a unified, browser-based terminal built to simplify cloud service deployment and streamline the generation of standardized network configurations across desktop and mobile clients.

Because network conditions and routing behaviors are constantly evolving, this project avoids static or one-size-fits-all claims. Instead, it provides a flexible, step-by-step workbench that empowers users to deploy their own cloud endpoints and adapt their connection parameters to match their current network environment.

Every operation—from cryptographic key derivation to configuration synthesis and vector QR generation—executes **100% locally inside your browser** from a single standalone `.html` file, ensuring complete privacy with zero external dependencies.

* **Get Started:** Always download the latest standalone `.html` release from the [**Releases**](https://github.com/Bermuda1998/BERMUDA-PORTAL/releases) section and open it directly in any modern browser.

## 🇮🇷 هدف و فلسفه پروژه

**برمودا پورتال (Bermuda Portal)** یک ترمینال تحت وب، یکپارچه و کاملاً مستقل است که با هدف ساده‌سازی فرآیند راه‌اندازی سرویس‌های ابری و تولید استاندارد کانفیگ برای کلاینت‌ها و سیستم‌عامل‌های مختلف توسعه یافته است.

با توجه به اینکه ساختار شبکه‌ها و شرایط ارتباطی همواره در حال تغییر و پیچیده‌تر شدن هستند، هدف این پروژه ارائه وعده‌های مطلق یا راه‌حل‌های ثابت نیست؛ بلکه فراهم کردن یک محیط کاربری پویا، شفاف و گام‌به‌گام است تا کاربران بتوانند زیرساخت شخصی خود را به سادگی مستقر کرده و پارامترهای اتصال را متناسب با شرایط روز شبکه خود تنظیم و مدیریت کنند.

تمامی بخش‌های این پورتال در قالب یک فایل `.html` مستقل طراحی شده‌اند و بدون نیاز به هیچ سرور واسطی، **۱۰۰٪ به صورت محلی در مرورگر دستگاه شما** اجرا می‌شوند تا امنیت و حریم خصوصی اطلاعاتتان کاملاً محفوظ بماند.

* **دریافت آخرین نسخه:** همواره آخرین فایل `.html` منتشرشده را از بخش [**Releases**](https://github.com/Bermuda1998/BERMUDA-PORTAL/releases) دانلود کرده و مستقیماً در مرورگر خود باز کنید.
