# 🛡️ Security Policy & Official Distribution

## 📦 Official Releases & Integrity

All official **Bermuda Portal** standalone `.html` builds are published exclusively through the official GitHub [**Releases**](https://github.com/Bermuda1998/BERMUDA-PORTAL/releases) page and verified community channels.

* **Zero External Dependencies:** Official builds execute 100% locally inside the browser and never transmit private keys or session parameters to external servers.
* **Verification:** Always ensure you download the latest release directly from this repository rather than third-party mirrors.
